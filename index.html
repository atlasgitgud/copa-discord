    Banner

    Podés subir una imagen, un GIF o un video (mp4/webm, sin sonido, se repite solo). Ideal horizontal y ancho. Con la barra elegís qué parte se ve. Los GIF y videos se suben al repo al toque, así que necesitás la conexión con GitHub configurada.

    Conexión con GitHub (para publicar)

    El token queda guardado solo en este navegador. Creá uno en GitHub → Fine-grained tokens, elegí solo este repositorio y dale permiso Contents: Read and write. Al publicar se actualiza el archivo data.js del repo y en 1–2 minutos lo ve todo el mundo.
